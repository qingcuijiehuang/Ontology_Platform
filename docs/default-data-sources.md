# 数据源接入指南（Data Source Guide）

平台**不内置任何数据集**。「接入数据源」面板只提供两种接入方式，
所有数据都来自用户自己 —— 自动解析上传的 JSON 文件，或手动填写数据源地址。

```
接入数据源面板
├── 已接入的数据源（初始为空，可逐条测试 / 删除）
└── 自定义接入
    ├── 自动解析接入 —— 上传 JSON 文件（推荐入口）
    └── 或手动填写 —— JSON 文件（默认）/ REST API / SPARQL / GraphQL
```

## 一、自动解析接入（上传 JSON 文件）

入口：「接入数据源 → 自定义接入 → 自动解析接入」，支持点击选择或拖拽上传。

- **扁平行数组**：`[{ "order_id": 1, ... }, ...]`，也兼容
  `items` / `rows` / `results` / `data` 包装、GraphQL `data` 包装、
  SPARQL JSON `results.bindings`，以及单个对象；带 BOM 的文件也能解析。
- **多实体分桶图**：`{ metadata, objects: { 实体名: [...] }, relationships: [...] }`
  这类文件会按桶拆开 —— 一个桶一个数据源，`relationships` 可选接成关系表。
- 自动识别本体实体（列名 / 桶名打分匹配）并生成列映射；识别不出时可在
  预览里手动选择实体，映射会实时重算。
- 数据只存在浏览器内存里（`localRows`），**不会上传到任何服务器**，
  离线可用且不受 CORS 限制；代价是刷新页面后需要重新上传。
- 单个文件上限 8 MB、最多保留 5000 行，超出会截断并在预览里明确提示。
- 重复上传同一份文件会**原地刷新**对应数据源，不会堆出重复项。

## 二、手动填写

入口：「接入数据源 → 自定义接入手动填写 → 添加数据源」。

| 字段 | 说明 |
|------|------|
| 名称 | 数据源显示名 |
| 类型 | **JSON 文件（默认且首选）** / REST API / SPARQL / GraphQL |
| URL | 数据源地址 |
| 自定义 Headers | 可选，JSON 对象（如 `{ "Authorization": "Bearer ..." }`） |

各类型的解析口径与自动解析一致：REST / JSON 文件拉取后走同一套
行提取（`pickRows`），SPARQL 解析 `results.bindings`，GraphQL 解析 `data`。

## 三、已接入数据源管理

- 每条数据源可**测试连接**（与真实请求同参，避免假阳性）或**删除**。
- 顶部提供**已接入数**统计、**「存入本体库」**与**「清空全部」**按钮。
- 接入后可在右侧「实例浏览」查看数据表格，系统按**列映射**把源系统字段
  翻译成本体属性，自然语言查询也会自动引用这些真实数据。

## 三之二、把数据源存入本体库

顶部的**「存入本体库」**会把**当前本体 + 已接入的全部数据源**存成同一条
「我的」条目（见 `src/lib/userOntologyLibrary.ts`），之后在本体库里加载它，
本体与数据源一并恢复。

保存的内容与边界：

| 保存 | 不保存 |
|------|--------|
| 名称、类型（REST / SPARQL / GraphQL / JSON 文件）、URL | 本地 JSON 文件的**行数据**（`localRows`） |
| Headers、映射实体（`entityTypeId`）、列映射 | 一次性的抓取状态（成功/失败/时间戳） |

- **本地文件的行数据不入库**：上千行原始数据会撞 localStorage 配额。
  入库时剥离并打上 `needsFileReupload` 标记；加载后该数据源显示
  「需重新上传文件」，抓取层也不发无意义的 `local://` 请求（直接返回中文提示）。
- **`endpoints` 参数三态语义**（`saveUserOntology`）：不传 = 不动已存的数据源
  （「导入 RDF → 存入本体库」走这条）；传数组 = 整体替换（数据源面板走这条，
  删掉某个源后再存会真的少一个）；传空数组 = 清空。
- 加载条目时，只有**条目里确实存过数据源**（`endpoints` 是数组）才整体恢复；
  从未存过（`undefined`）则不动用户当前接入的数据源，避免误清空。
- 同名覆盖：先「存本体」后「存数据源」补齐到同一条目，不会变成两张卡。

## 四、相关代码

| 文件 | 作用 |
|------|------|
| `src/components/EndpointConnector.tsx` | 接入面板（自动解析 + 手动填写 + 已接入管理 + 存入本体库） |
| `src/lib/jsonAutoImport.ts` | JSON 自动解析：行提取、分桶展开、实体识别、列映射 |
| `src/lib/datasetFetcher.ts` | 数据抓取（本地 `localRows` 直读，不走网络） |
| `src/lib/userOntologyLibrary.ts` | 本体库本地保存区（本体 + 数据源打包存取） |
| `src/store/appStore.ts` | `endpoints` 状态：初始为空，`addEndpoint` / `setEndpoints` / `resetEndpoints` |
