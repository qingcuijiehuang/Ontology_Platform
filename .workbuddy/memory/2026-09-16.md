## 沉淀的工程约定
1. **主题类要挂两处**：`index.html` 首屏脚本（`:root`）+ `themeClass()`（`.app-container`），
   这样既要防首帧闪烁，又要让 `<body>` 之外的容器拿到正确的级联。改一处必须改两处。
2. **「默认值」要能被测试锁住**：模块加载期求值的默认值（如主题）不是不可测，
   `vi.resetModules()` + 动态 import 就能覆盖多个存储场景，别因此退化成浏览器脚本验证。
3. **截图脚本必须处理遮罩 / 引导**：任何全屏 dim 的 UI 都会让「配色类」截图失真，
   截图前先关掉它，否则等于没有视觉证据。
4. **本地化要挑「只用于展示」的字段**：`metadata.name` 只喂卡片标题所以可安全中文化；
   凡是被当 key / 路径用的字段一律不碰，先查引用再动手。
